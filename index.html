Envío masivo (todos los alumnos cargados)
Usa el Formato y Asesor de arriba para los 0 alumnos cargados. Por seguridad, el navegador solo permite abrir una ventana por clic — cada clic te lleva al siguiente borrador/chat automáticamente. Estos mismos selectores se usan al abrir el detalle de un alumno puntual. Si un alumno tiene más de un número cargado, "Abrir todos los WhatsApp" abre un chat por cada número suyo.
Estados de cuenta
Este Excel es independiente del de recordatorios. Podés cargar más de un archivo (de a uno o seleccionando varios juntos): los alumnos se van acumulando en la misma lista — si un alumno ya estaba cargado (mismo nombre y cédula), se actualiza con los datos del archivo más nuevo en vez de duplicarse. Usá "Vaciar lista" para empezar de cero. Columnas esperadas: Nombre, Telefono, Correo, Monto (cuota), Cédula, Pagaré, Plazo. Opcionalmente podés agregar columnas "Telefono 2" y "Telefono 3" para guardar números adicionales del alumno. Lo que no venga en el archivo queda en blanco para completar a mano.
